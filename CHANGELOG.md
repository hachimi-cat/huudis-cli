# Changelog

## 0.6.0
- Access keys: with `HUUDIS_ACCESS_KEY_ID` + `HUUDIS_SECRET_ACCESS_KEY` set, every call is signed `Huudis-HMAC-SHA256` with the key instead of using the stored sign-in (the key acts as its user within the user's IAM policies).
- `huudis api app …` authenticates as your OIDC app with `HUUDIS_CLIENT_ID` + `HUUDIS_CLIENT_SECRET` (HTTP Basic); it used to send the sign-in bearer, which `/app/*` refuses.
- `HUUDIS_WORKSPACE_ID` sends `X-Huudis-Workspace-Id`.
- `huudis --version` prints the package version (it said 0.5.0).

## 0.5.2
- `huudis api <area> <action>`: every feature route of the Huudis API as a command, flags typed from the API spec (generated by scripts/apigen.sh), using the token `huudis auth login` stored.

## 0.5.1
- Package metadata now points at the public mirror repo (github.com/hachimi-cat/huudis-cli).
